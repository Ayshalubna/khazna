# IT Acceptable Use Guidelines

## Personal use

Limited personal use of company internet is allowed during breaks, provided it does not affect work or breach any law.

## Software

Only software from the company software centre may be installed. Requests for new software go through the IT Service Desk.

## Guest Wi-Fi

Visitors use the "Sadeem-Guest" Wi-Fi network, which is separated from the corporate network. Guest passwords change every week.

## Printing

Confidential documents must be printed with secure print release at the printer.

## Monitoring

Company systems are monitored for security purposes. Employees should have no expectation of privacy when using company devices.
